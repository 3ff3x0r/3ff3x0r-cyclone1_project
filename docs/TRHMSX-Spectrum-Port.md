# Porting the ZX Spectrum to the TRHMSX
## Engineering handoff · 24 November 2026

**Base the port on Sorgelig’s ZX_Spectrum-128K_MIST, with a new TRHMSX top level.** It provides a common CPU/ULA implementation, 128K and +3 paging, a Pentagon timing path, tape logic, and both families of disk controller. Its MiST host, RAM layout and clock tree all require work. A direct recompile cannot fit. Build a separate Spectrum configuration selectable by reprogramming the board. Switching Spectrum machines and ROMs happens inside that one configuration. Co-resident MSX and Spectrum cores or a flash multiboot menu would be separate projects.

This is a source-based design and work breakdown. There is no fitted TRHMSX bitstream or measured hardware result. The electrical reference is the published v1.51 production board. Check the silkscreen, U5 marking and any owner modifications before using its pin map on another revision.

### 2. Hardware contract for the published board

The BOM lists an **EP1C12Q240C8N**, **21.47727 MHz** crystal, **MT48LC16M16A2TG** SDR SDRAM, and **EPCS4** configuration flash. U5's nominal 16M × 16 organization gives 32 MiB. Your reported 4 MB is a reasonable working ceiling until the fitted chip and address lines are tested. The design below fits its external allocations inside the first 4 MiB. The harder resource limit is *inside* the FPGA: 12,060 LEs, 52 M4K blocks, 239,616 total RAM bits including parity, two PLLs.

| Interface | Board and package mapping for the first build |
|---|---|
| Clock and RAM | OCM pClk21m = U1 pin 28, pMemClk = pin 38. Match every U5 address, bank, DQ, DQM, CKE and command line against the netlist. Use byte enables on the x16 memory for the Z80's byte writes. |
| SD J4 | SPI CS = DAT3/U1-65, CLK = U1-63, MOSI = CMD/U1-64, MISO = DAT0/U1-62. DAT1/2 unused in SPI. The detect pad has no useful named card-detect signal in the production netlist. Provide retry by command timeout and explicit remount. |
| PS/2 J7 | DATA = U1-67, CLK = U1-68. Native PS/2 and the onboard CH559 USB-to-PS/2 path must coexist electrically. Begin with receive-only inputs. For host transmissions drive low or release, with pull-ups and voltage interface as on this revision. |
| VGA J14 | Connector pins 1, 2, 3 = RGB, 13 = HS, 14 = VS. The OCM QSF has six bits per DAC channel. Keep HS/VS separate. Leave DDC released unless implemented. |
| JOY1 J15 | DE-9 pins 1,2,3,4 = up, down, left, right → U1 pins 1,3,5,7. Buttons A/B on DE-9 6,7 → U1 2,4. Strobe on DE-9 8 → U1 6. Pin 5 supplies +5 V, pin 9 is ground. |
| JOY2 J10 | Same DE-9 ordering → U1 8,12,14,16 for directions, 11,13 for A/B, 15 for strobe. Verify both with an actual MSX two-button stick. Match the OCM conventional stick strobe state at the connector and keep the six switches as inputs. |
| Audio / tape | J11 tip and ring are SOUND_L and SOUND_R. The production netlist identifies a stereo output, with no EAR input on J11. Use the board DAC path for beeper, PSG and selectable MIC recording. Trace any added tape input on the owner's unit separately. |
| Programmer J8 | Its nets are AS_CK, AS_DI, AS_DO, AS_CS and configuration controls. It is an Active Serial header. Use the documented EPCS4 programming and recovery process. A volatile JTAG .sof test requires separately verified access to real JTAG signals. |
| Cartridges and ESP | Preserve idle levels on both slots, deassert select/read/write, release shared data lines, keep ESP pins idle. The shipped ESP8266 provides a network interface, not a MiST storage host. No cartridge or ESP firmware is required for the Spectrum release. |

The board owner should keep the known-good **complete OCM flash image including EPBIOS**, or a verified readable flash backup, plus programmer settings. Build a separate Spectrum .pof for the fitted EPCS4. Derive conversion settings for Spectrum explicitly. Do not carry OCM's EPBIOS offset into the Spectrum image or assume both images fit together. Schedule the first physical flash with the owner after the rollback path is available.

### 3. Donor extraction and first fitting experiment

1. Create boards/trhmsx_v151/ with a Quartus project, top module, pin map, constraints, PLL files for Cyclone I, and an explicit source manifest. Keep imported files under vendor/ and localized adaptations under rtl/. The MiST QSF targets EP3C25E144C8 using a 27 MHz board input. Importing its QSF would target the wrong board.
2. Extract CPU bus, ULA and page-register logic from zxspectrum.sv. Replace mist_io status/menu bits with a small latched machine configuration. Replace ioctl ROM loading, virtual disk handshakes and joystick events with explicit interfaces. Remove the MiST OSD, General Sound, turbo modes, ULA+/Timex, Multiface, mouse, second PSG and unused disk paths from the first elaboration. Preserve base FE keyboard, beeper, EAR and border behavior.
3. Replace vendor-generated Cyclone III IP. In particular, vram.v declares **32768 × 8 = 262,144 bits**. This one instance exceeds the EP1C12's entire 239,616-bit memory. For standard Spectrum video, mirror only offsets 0..6911 of screen banks 5 and 7. A simple layout is two 8 KiB slots, typically 32 of 52 M4Ks at 512×8. Two packed 6912-byte slots can save blocks if the fitter confirms it. Address the mirror with the *physical bank*, even when paging makes it visible at 0000, 4000 or C000. All RAM writers, including future snapshot/loader DMA, must update it. Test read-during-write timing. If FDC buffers crowd it out, move ULA fetches to reserved SDRAM slots or prefetch a scanline.
4. Use a small generated diagnostic/boot ROM, two small VGA line buffers, one PSG and a sector buffer in the first fit. Keep Spectrum ROM banks and machine RAM in SDRAM. Produce fitter, RAM block, PLL, worst slack and unconstrained-path reports. Report the actual resource deltas after adding each subsystem. A planning target of at least 10% free LEs at the base milestone is a margin for disks, not a passing measurement.
5. Exercise the old compiler on real source immediately. Watch for SystemVerilog aggregate resets such as the array assignment in ym2149.sv, inferred multidimensional memories in u765.sv, and .*-connected ports in the top. Convert only rejected constructs to explicit equivalents, with identical simulation traces. Use a mixed-language simulator or a documented T80 VHDL synthesis-to-Verilog step for full integration. A Verilog-only lint pass cannot validate T80.

Sources: [donor top](https://github.com/sorgelig/ZX_Spectrum-128K_MIST/blob/9713924d41865f3d5712f9daf8fbd9b0489f8697/zxspectrum.sv), [VRAM](https://github.com/sorgelig/ZX_Spectrum-128K_MIST/blob/9713924d41865f3d5712f9daf8fbd9b0489f8697/vram.v), [ULA](https://github.com/sorgelig/ZX_Spectrum-128K_MIST/blob/9713924d41865f3d5712f9daf8fbd9b0489f8697/ula.sv), [FDC](https://github.com/sorgelig/ZX_Spectrum-128K_MIST/blob/9713924d41865f3d5712f9daf8fbd9b0489f8697/u765.sv).

### 4. Contracts to freeze before parallel work

| Boundary | Implementable agreement |
|---|---|
| Machine configuration | profile_id, RAM size, timing_id, paging_id, ROM bank set, PSG enable, disk kind and input mapping. Latch atomically during cold reset. Guest reset preserves selected ROMs. A reserved physical key at reset enters recovery. |
| Memory | Separate CPU and loader clients with byte address, read/write, write byte, request/accept, read-valid/read-byte. Allow one outstanding read per client initially. Exactly one commit per write. Resolve physical bank before SDRAM or screen mirror selection. Keep all CS, write enables and ownership deterministic during reset. |
| Video | ULA emits pixel-enable, palette index, border-inclusive raster, sync and blanking. Display logic consumes this stream without backpressure on the guest. The CPU, ULA and PSG share a model timebase. Display scanout has its own output timing contract. |
| Input and audio | Keyboard backend emits held 8×5 matrix; joysticks emit six positive-logic switches each. Guest FE read combines all selected rows. Core accepts ear_bit and emits mic_bit, beeper_bit and PSG samples. Only the board wrapper controls physical pads. |
| Media | Physical sector interface uses 32-bit LBA, 512-byte block, direction, request, completion and error. A mounted image exposes file-relative blocks with length and write protection. Translate a file offset through the FAT cluster chain before submitting a physical LBA. Refuse requests crossing file length. |
| Boot and diagnostics | Small Z80 boot environment owns SD at reset. It validates and stages a new profile/ROM set, initializes RAM as required, then sets a one-shot commit latch. Hardware asserts guest reset, hides the boot overlay and releases the CPU at address zero only after memory and clocks are ready. Failures stay in the loader with a visible error. |

Proposed external *byte* map: 000000–01FFFF guest RAM (eight 16 KiB banks), 020000–02FFFF active ROM (four banks), 030000–03FFFF staging ROM, 040000–07FFFF loader workspace/media metadata, 080000–0FFFFF optional media cache. Higher addresses remain free. On-chip boot ROM is a reset overlay. The map is private to the fabric. Guests only see their selected paging rules. Cap all DMA bounds independently of file metadata. A host-generated SD index can record ROM hashes and bank order while the small loader checks length and CRC on-device.

### 5. Model and ROM selector

Treat the chosen firmware and the emulated motherboard as separate fields in the menu. For example, list “TK90X 60 Hz / Guerra [version]” only after testing that pair. Store ROM pages in explicit manifest order rather than deriving bank order from filenames.

| Profile | Behavior and acceptance test |
|---|---|
| Sinclair 16K | One 16 KiB ROM, 4000–7FFF populated, no writable high RAM. Test writes at 8000 and FFFF, unmapped/open-bus behavior by phase, 16K BASIC RAMTOP and a real 16K title. Using a 48K ROM can be correct; exposing all 48K of RAM is a failure. |
| Sinclair 48K PAL | Three 16 KiB RAM segments, original ULA timing and contention, keyboard/border/EAR/MIC. AY off by default, optional external AY mode. Target 224 T-states × 312 lines = 69,888 per frame at nominal 3.5 MHz. Test floating bus, border splits and a pulse-loaded program. |
| Sinclair 128K and grey +2 | Eight RAM banks, two ROM banks per set, 7FFD bank select, screen 5/7, ROM select and paging lock. Target 228 × 311 = 70,908 T-states per frame at about 3.547 MHz. | +2A | Four ROM pages, 1FFD and 7FFD interaction, special all-RAM maps 0/1/2/3, 4/5/6/7, 4/5/6/3, 4/7/6/3 in ascending CPU windows. Validate contention in banks 4..7, changed I/O behavior and FE behavior. Test instruction fetches and writes in every window of every all-RAM mode. |
| +3 | +2A-family paging and gate array plus uPD765-compatible controller and mounted DSK image. Test enumeration with CAT, read a multi-sector file via +3DOS, then SAVE to a disposable writable image, remount and verify bytes. BASIC boot alone counts as ROM/paging bring-up. |
| TK90X | Identify 16K/48K variant and ROM revision. Implement a TK-specific timing/I/O profile with independently selected 50/60 Hz as applicable. Test fallback “TK ROM on Sinclair hardware” under that explicit label. |
| Rodolfo Guerra | This is a ROM author with multiple images. Catalog each by exact release, intended TK/Spectrum platform, size, page order and hash. Test startup plus one documented enhancement and standard tape loading. Avoid a single universal “Guerra machine.” |
| Russian models | Deliver a Russian-language ROM selectable on an identified compatible profile, and a named **Pentagon 128** hardware profile. Important donor defect to address: ula.sv's contendAddr tests the 4000 window and odd paged banks at C000. That rule alone cannot implement +2A/+3 banks 4–7, especially in all-RAM mode. Pass the resolved physical bank and explicit contention profile into the ULA. Test the wait pattern and phase as well as bank membership. Compare FE I/O contention and floating bus independently. Donor “correct timings” in the README is insufficient as an acceptance test.

### 7. Implementation choices that affect compatibility

**Clock and video.** The donor takes 27 MHz and its divider comments assume a 112 MHz system clock. Start with a board-reference-derived SDRAM clock that meets U5 timing. A candidate such as 4 × 21.47727 ≈ 85.909 MHz is an experiment, contingent on PLL fit, phase and static timing. Derive model-specific enables with a common phase accumulator if exact PLL ratios are unavailable. Preserve CPU/ULA phase ordering and measure average clock error and single-tick jitter. Do not substitute the MSX CPU rate. In native display mode the 48K line rate is 3.5 MHz / 224 = 15.625 kHz, giving 31.25 kHz after doubling and about 50.08 Hz vertical. The 128K target gives approximately 31.11 kHz doubled. A CRT may accept this while an LCD rejects 50 Hz. For that LCD, use an independent 640×480-class 59.94/60 Hz output, a packed indexed framebuffer in external RAM and completed-frame swaps. Repeat whole frames when needed; preserve emulation/audio speed. Test with both displays and log their actual accepted rates. A line doubler alone cannot convert frame rate.

**SD without a host processor.** A physical card connected over SPI does not deliver MiST's ioctl or virtual-disk callbacks. The simplest complete implementation is a Z80 loader that runs before the guest and stages a selected TAP or an entire small disk in reserved SDRAM. For the first disk release use mounted, read-only images; enforce length limits before copying. Serve the FDC's file-relative sector requests from this memory. A later writable implementation can track dirty sectors and flush through the loader on explicit eject. Keep the dirty map across guest reset, show pending writes before profile changes, refuse silent eviction, and report a failed flush. A full live FAT filesystem in FPGA logic is unnecessary. With a resident image too large to stage, precompute a bounded FAT extent table during mount and use a sector cache; reject images exceeding advertised limits. DivMMC/esxDOS is optional for in-guest browsing and requires its own mapping, firmware and card ownership arbitration.

**PS/2, AY and two-button joysticks.** Scan address bits A8..A15 and AND selected active-low keyboard rows. Map PC modifiers to CAPS SHIFT/SYMBOL SHIFT, including overlapping synthetic chords; track per-source key state to avoid stuck keys. Default to switchable Sinclair Interface 2 mode for two players: one stick maps left/right/down/up/fire to 6/7/8/9/0, the other to 1/2/3/4/5. Offer Kempston for player 1 (bits 0..4 right/left/down/up/fire) and Sinclair for player 2. Make button B configurable per stick as a distinct shortcut, e.g. SPACE or symbol shift, or optional extended Kempston bit for software that recognizes it. Classic protocols expose one standard fire each. Test A and B independently, combined, and across players. Place AY select/read at FFFD and data write at BFFD with model-appropriate partial decoding. Qualify a single PSG at the model's half-CPU clock, including 16-level behavior, envelope shape/retrigger, noise, one I/O port and unused-register reads against an AY reference. The donor YM2149 has two I/O ports and selectable level curves. Its wrapper needs explicit AY behavior. Mix with beeper at adequate accumulator width before limiting to the two six-bit DAC paths; keep a clean MIC recording mode.

**Tape.** Route FE output bit 3 to a selectable recording channel and beeper bit 4 to the normal mixer. For playback, feed a normalized EAR level at FE input bit 6 with model-specific idle behavior. Use real-time pilot/sync/data pulses so Guerra or TK ROMs can load without Sinclair ROM-address traps. Stage SD TAP playback to avoid filesystem stalls in the pulse train. Test SAVE to an external recorder, recover the recording with an independent decoder, and re-load it. For real cassette input, first identify any extra jack or comparator on the actual unit. A stock v1.51 can add a conditioned, voltage-compatible digital EAR input on a verified available expansion signal, with a documented adapter and connector pin. Keep that feature marked adapter-required until tested. J11 output alone serves recording.

### 8. Release evidence and fallback decisions

| Failure signal | Action and exit test |
|---|---|
| Core fails to fit or timing is negative | Inspect per-entity fitter reports. Remove unused host logic and special modes at elaboration, reduce mirror size or move fetches to SDRAM, share disk buffers, then refit. If both disk controllers still cannot coexist, publish separate Sinclair/+3 and Pentagon/Beta builds with shared SD layout and explicitly document the lost single-bitstream selection. |
| Boot succeeds but games tear or run too fast | Compare raster/INT phase and contention traces on each model. Count unexpected CPU stalls, assert each screen write reaches the mirror exactly once, and test screen switches mid-frame. LCD frame repeats must never feed back into guest clocks. |
| SD works with one card, or image reads corrupt other files | Test SDSC/SDHC units, slow cards, fragmented FAT, sector boundaries, wrong card after eject and bounded writeback. Compare complete disposable disk and card images before and after writes. |
| FPGA works in simulation, board behaves randomly | Verify reset after PLL lock, SDRAM initialization delay, synchronizers, pin directions, QSF timing coverage and data-valid phase. Run low-speed and full-speed memory patterns. Check lower 4 MiB for aliasing independently of optional larger RAM detection. |
| Unknown clone or ROM starts but software fails | Keep that combination experimental. Record the exact image hash and model reference, then add a failing timing, port or paging regression before changing common logic. |
| Physical board or peripherals unavailable | Publish simulated, fitted, and board-tested as separate columns. No physical evidence means the corresponding row remains open. |

**First milestone worth running on your board:** a standalone bitstream that starts from reset, shows a diagnostic at ~31 kHz, passes the lower-memory/byte-lane test, sees the PS/2 keyboard and both two-button joysticks, and reads a known SD sector. **First usable Spectrum release:** cold-select a 48K ROM and TAP from FAT SD, load through the ROM's EAR routine, play with either joystick mapping, and return to the selector. **Full release:** every requested named profile has a separate boot, timing, input, sound and media result; +3 and Pentagon also pass their native disk tests. Retain the Quartus reports, SD fixture hashes and bench table alongside the exact source revision.
